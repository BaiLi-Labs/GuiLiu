登录 GuiLiu

使用管理员或团队成员账号登录。登录态由 HttpOnly Session Cookie 维护。

首次启动：设置 GUILIU_ADMIN_PASSWORD 后启动，或运行 guiliu user add -username admin -role admin。
本地调试可运行 make dev（关闭认证，不要对外暴露）。忘记密码可用 guiliu user passwd 重置。
